## 單集說明

Hi, welcome to The Ship It Show！這是開台的第 0 集。

先聊聊為什麼要開這個節目、為什麼叫「Ship It」，以及我們每一集要找的「Aha」是什麼。

接著進入正題：你有沒有照著 AI 的建議，打過一行 pip install？AI 寫程式越來越方便，但它推薦的套件，可能是它自己「編」出來的。更可怕的是，已經有人在等你照著裝。

這一集你會聽到：

- AI 為什麼會發明不存在的套件（套件幻覺 Package Hallucination）
- 研究數據：這件事到底有多常發生
- 駭客怎麼利用這個漏洞（Slopsquatting）
- 真實案例：一個 AI 發明的假套件，被下載超過一萬五千次
- 五個保護自己的習慣

下一集，我會訪問 pickfit 的創作者念誠：一個「每個工具都先在沙盒裡實際測過，才推薦給你」的產品。
