# 新增一集

每次有新的一集上架，照下面四步更新。push 到 `main` 之後約 1–2 分鐘，網站會自動把它顯示成「最新一集」，前一集會移到「往期節目」。

## 1. 建立單集資料夾

複製 `episodes/_template/`，改名成集數，例如 `episodes/EP01/`。

- `cover.jpg`：單集封面（正方形，建議 900×900 以內、200 KB 左右）
- `README.md`：照範本填入單集說明、章節、參考資料、收聽連結

## 2. 更新 `episodes.json`

在陣列**最上面**加一筆。網站會把第一筆當成最新一集。

```json
{
  "id": "EP01",
  "title": "單集標題",
  "summary": "一兩句單集簡介，顯示在最新一集卡片上",
  "next": "下集預告：……（沒有就留空字串）",
  "cover": "episodes/EP01/cover.jpg",
  "date": "2026-12-01",
  "links": {
    "spotify": "單集的 Spotify 連結",
    "apple": "單集的 Apple Podcasts 連結",
    "youtube": "單集的 YouTube 連結"
  }
}
```

| 欄位 | 說明 |
|---|---|
| `id` | 集數，例如 `EP01` |
| `title` | 單集標題 |
| `summary` | 卡片上的簡介，建議 60 字內 |
| `next` | 下集預告，可留空 |
| `cover` | 封面路徑 |
| `date` | 上架日期 `YYYY-MM-DD` |
| `links` | 單集連結；留空的話，按鈕會改連到節目首頁（`index.html` 裡的 `SHOW`） |

## 3. 更新 `README.md` 的集數表

在集數表加一行，最新的一集放最上面或最下面都可以，但整份表要一致。

## 4. 檢查後 push

- 打開 https://adelawen.github.io/shipit-show/ 確認新的一集有出現、封面和按鈕正常
- 手機上看一次

## 節目層級的連結

Spotify、Apple Podcasts、YouTube、Instagram、Threads、LinkedIn 的節目／帳號網址寫在 `index.html` 裡的 `SHOW` 區塊，只需要設定一次。

## 什麼不能放進這個 repo

這是公開 repo。以下內容一律放在私人的製作 repo，不放這裡：

- 研究資料、訪綱、主持人腳本
- 來賓聯絡資訊、往來信件、未同意公開的內容
- 原始音檔、未剪輯的錄音
- 任何金鑰、帳號密碼
